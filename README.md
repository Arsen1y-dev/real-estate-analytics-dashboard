# Real Estate Analytics Dashboard

Интерактивный веб-дашборд для исследования выборки объектов недвижимости по загружаемому CSV: **любые столбцы файла**, конструктор графиков, тёмная и светлая тема.

**Стек:** React 19, TypeScript, Vite 6, Recharts, Papa Parse.

## Возможности

- **Все столбцы CSV** попадают в таблицу данных; для каждого столбца автоматически определяется тип: *числовой* (если ≥85% непустых значений удаётся разобрать как число) или *категориальный*. Колонки `тип_дома_*` принудительно считаются категориальными.
- **Конструктор графиков:** добавляйте любое количество визуализаций — **гистограмма** (числовой столбец), **точечная диаграмма** (два числовых столбца), **столбцы по категориям** (частоты значений). Список графиков можно редактировать и удалять отдельные карточки.
- После загрузки по умолчанию строится гистограмма по **первой числовой** колонке (если она есть).
- Записи, прошедшие фильтры, участвуют во всех графиках без искусственного лимита по количеству строк (кроме оговоренной выборки для scatter).
- **Боковые фильтры** (если в файле есть колонки с точными именами `Цена`, `Общая площадь`, `Количество комнат`): диапазоны цены и площади, комнатность. Пересчёт с `useDeferredValue` / `startTransition`.
- **Комнатность по умолчанию:** без ограничения (все значения); клик по кнопке комнатности сужает выбор.
- Если этих трёх колонок нет, боковые фильтры не применяются — отображаются все загруженные строки (кроме полностью пустых).
- Краткая сводка в шапке и подписи к графикам (медиана, IQR, число категорий и т.д.).
- **Кэш `localStorage` (версия 2):** датасет и сводка по столбцам; тот же файл открывается без повторного парсинга. Лимит ~4.5 МБ JSON. Старый кэш v1 не используется.
- Scatter после фильтрации строится по **равномерной выборке** до **1200** точек; гистограммы и категории — по полной выборке.

## Формат CSV

Регистр имён колонок важен. Типичный набор (все поля необязательны, кроме того что вы используете в графиках):

| Колонка | Описание |
|--------|----------|
| `Цена` | Число; при наличии — участвует в боковом фильтре «цена» |
| `Общая площадь` | м²; фильтр «площадь» |
| `Количество комнат` | Число; фильтр по комнатности |
| `Расстояние до центра (км)` | Число; как и любой другой столбец — доступен в графиках |
| `тип_дома_<название>` | Флаги `0`/`1`; в данных добавляется агрегат `houseType` |

Пустые строки отбрасываются. Ячейки парсятся как числа, где возможно (пробелы, запятая, символы валюты).

## Запуск

Требуется **Node.js 18+**.

```bash
npm install
npm run dev
```

По умолчанию: [http://localhost:3000](http://localhost:3000) (см. `vite.config.ts`).

Сборка продакшена:

```bash
npm run build
npm run preview
```

При сборке Vite выделяет отдельные чанки для React, Recharts и Papa Parse.

## Структура проекта

Код в **`src/`**, алиас `@/` → `src`.

| Путь | Назначение |
|------|------------|
| `index.html` | Оболочка; скрипт `/src/main.tsx` |
| `src/main.tsx` | Вход |
| `src/App.tsx` | Состояние, фильтрация, вёрстка |
| `src/types.ts` | `DataRow`, сводка по столбцам, описания пользовательских графиков |
| `src/cache.ts` | Кэш датасета v2 |
| `src/theme.ts` | Тема и цвета Recharts |
| `src/domain/dataset.ts` | Нормализация ячеек, сводка, `houseType` |
| `src/domain/filters.ts` | Фильтры строк, стартовое состояние из кэша |
| `src/domain/chartDefaults.ts` | График по умолчанию после загрузки |
| `src/utils/` | Числа, формат, статистика, выборка scatter, id |
| `src/components/` | `FileUpload`, `FilterPanel`, `ChartBuilderPanel`, `DynamicChartGrid`, `DashboardStats`, карточки, иконки |
