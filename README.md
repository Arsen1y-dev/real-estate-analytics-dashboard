# Real Estate Analytics Dashboard

Интерактивный веб-дашборд для исследования выборки объектов недвижимости по загружаемому CSV: фильтры, несколько типов графиков, тёмная и светлая тема.

**Стек:** React 19, TypeScript, Vite 6, Recharts, Papa Parse.

## Возможности

- Загрузка CSV с произвольным числом строк; отображаются **все** записи, прошедшие фильтры (без искусственного лимита по количеству объектов).
- Фильтры по цене, площади и комнатности с отложенным пересчётом (`useDeferredValue` / `startTransition`) для плавного UI.
- Выбор набора визуализаций (гистограммы, scatter, средние по типу дома и комнатам и др.).
- Интерактив: клик по столбцу гистограммы сужает диапазон фильтра; кнопки сброса к базовым границам.
- Краткая аналитика под графиками (медианы, размах и т.д.).
- **Кэш в `localStorage`:** после первого разбора файла данные сохраняются; повторный выбор того же файла и перезагрузка страницы не запускают парсинг заново (ограничение по размеру ~4.5 МБ JSON).
- Scatter-графики для читаемости строятся по **равномерной выборке** до 1200 точек; гистограммы и агрегаты считаются по полной отфильтрованной выборке.

## Формат CSV

Заголовки колонок должны совпадать (регистр важен):

| Колонка | Описание |
|--------|----------|
| `Цена` | Число, допускаются пробелы и символы валюты |
| `Общая площадь` | м² |
| `Количество комнат` | Целое |
| `Расстояние до центра (км)` | Число |
| `тип_дома_<название>` | Одна или несколько колонок; в строке ровно одна помечена как активная (`1`) |

Строки с нечисловыми обязательными полями отбрасываются.

## Запуск

Требуется **Node.js 18+**.

```bash
npm install
npm run dev
```

По умолчанию: [http://localhost:3000](http://localhost:3000) (см. `vite.config.ts`).

Сборка продакшена:

```bash
npm run build
npm run preview
```

## Структура репозитория

| Путь | Назначение |
|------|------------|
| `App.tsx` | UI, графики, фильтры |
| `cache.ts` | Сохранение и восстановление датасета из `localStorage` |
| `types.ts` | Типы данных и фильтров |

## Публикация на GitHub

1. Создайте **пустой** репозиторий на GitHub (без README и без `.gitignore`), например `real-estate-analytics-dashboard`.
2. В каталоге проекта:

```bash
git remote add origin https://github.com/<ваш-логин>/real-estate-analytics-dashboard.git
git push -u origin main
```

При SSH замените URL на `git@github.com:<ваш-логин>/real-estate-analytics-dashboard.git`.
