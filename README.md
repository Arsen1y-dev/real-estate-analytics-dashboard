# Real Estate Analytics Dashboard


Интерактивный веб-дашборд: **произвольные столбцы файла**, конструктор графиков, фильтры по «ядру» колонок (если они есть в данных), тёмная и светлая тема, кэш последнего файла в `localStorage`.

**Стек:** React 19, TypeScript, Vite 6, Recharts, Papa Parse.

## Возможности

### Данные и типы столбцов

- **Все столбцы CSV** попадают в таблицу; для каждого столбца автоматически определяется тип: *числовой* (если ≥85% непустых значений удаётся разобрать как число) или *категориальный*. Колонки `тип_дома_*` принудительно считаются категориальными; служебное поле `houseType` в списках графиков скрыто.
- После загрузки по умолчанию строятся пресеты графиков по сводке (числовые и категориальные столбцы).
- Записи, прошедшие фильтры, участвуют в графиках без искусственного лимита по числу строк (кроме выборки для scatter).
- **Боковые фильтры** (если в файле есть колонки, сопоставленные с «ядром» — цена, общая площадь, количество комнат): диапазоны цены и площади, комнатность. Пересчёт с `useDeferredValue` / `startTransition`.
- **Комнатность по умолчанию:** без ограничения (все значения); выбор конкретных комнат сужает выборку.
- Если этих колонок нет, боковые фильтры не применяются — отображаются все загруженные строки (кроме полностью пустых).
- Блок **«Обзор рынка»**: KPI по текущей выборке (главная метрика крупнее, остальные — контекст), **автоинсайты** (цена, площадь, выбросы, комнатность и т.д.).
- Scatter после фильтрации строится по **равномерной выборке** до **1200** точек; гистограммы и категории — по полной выборке. На гистограммах, категориях и scatter доступен **Brush** (диапазон) с кнопкой «Весь диапазон».

### Конструктор графиков

- **Гистограмма** (числовой столбец), **точечная диаграмма** (два числовых столбца), **столбцы по категориям** (частоты значений). Список графиков можно переупорядочивать (drag-and-drop) и удалять.
- **Панель графиков:** тип визуализации завязан на допустимые столбцы, **поиск по названию** с подсветкой совпадений, блок **«Популярные поля»** (цена, площадь, комнаты — если есть в данных).
- Подписи категорий и заголовки приводятся к читаемому виду (в т.ч. `snake_case`, булевы значения).
- Экспорт карточки графика в **PNG** и **PDF**; в полноэкранном режиме те же действия в шапке модалки.

### UX

- **Skeleton** при парсинге CSV; **drag & drop** загрузки файла на стартовом экране.
- **Поделиться:** ссылка с закодированными фильтрами и набором графиков (параметр `?share=` в URL; рассчитано на тот же набор столбцов CSV).
- **Тема** оформления: нейтральный zinc + акцент indigo; предпочтение темы хранится отдельно для быстрого переключения.

### Кэш и localStorage

Используются **разные ключи** под датасет и UI:

| Ключ | Назначение |
|------|------------|
| `realty-dashboard-dataset-v2` | Кэш последнего загруженного CSV: данные и сводка (`CachedDataset`). Тот же файл (имя + размер + дата) открывается без повторного парсинга. Лимит ~4.5 МБ JSON; при превышении кэш не пишется, но сессия работает в памяти. |
| `realty-dashboard-ui-v1` | Фильтры и набор графиков по сигнатуре столбцов (`columnOrder`). При смене файла с другими столбцами подставляется своя запись или значения по умолчанию. |
| `realty-dashboard-theme-v1` | Только выбранная тема (light/dark) для быстрого чтения без разбора всего UI JSON. |


## Формат CSV

Регистр имён колонок важен. Типичный набор (поля необязательны, кроме используемых в графиках):

| Колонка | Описание |
|--------|----------|
| `Цена` | Число; при наличии — участвует в боковом фильтре «цена» |
| `Общая площадь` | м²; фильтр «площадь» |
| `Количество комнат` | Число; фильтр по комнатности |
| `Расстояние до центра (км)` | Число; как и любой другой столбец — доступен в графиках |


Пустые строки отбрасываются. Ячейки парсятся как числа, где возможно (пробелы, запятая, символы валюты).

## Запуск

Требуется **Node.js 18+**.

```bash
npm install
npm run dev
```

По умолчанию: [http://localhost:3000](http://localhost:3000) (см. `vite.config.ts`).

Сборка:

```bash
npm run build
npm run preview
```

При сборке Vite выделяет отдельные чанки для React, Recharts, Papa Parse; при первом экспорте графика подгружаются `html2canvas` и `jspdf`.

## Python-утилиты (опционально)

В каталоге `scripts/` — вспомогательные скрипты (pandas, офлайн-обработка данных):

- `requirements.txt` — `pip install -r scripts/requirements.txt`
- Нормализация имён колонок, типы столбцов, очистка категорий, группировка one-hot и т.д.

Они **не** входят во фронтенд-сборку.

## Структура проекта

Код в **`src/`**, алиас `@/` → `src`.

| Путь | Назначение |
|------|------------|
| `index.html` | Оболочка; скрипт `/src/main.tsx` |
| `src/main.tsx` | Вход |
| `src/App.tsx` | Состояние, фильтрация, вёрстка, шаринг, persist UI |
| `src/types.ts` | `DataRow`, сводка по столбцам, описания пользовательских графиков |
| `src/cache.ts` | Кэш датасета v2 (`localStorage`) и in-memory слой |
| `src/persistence/` | Ключи и настройки UI v1 |
| `src/theme.ts` | Тема и цвета Recharts |
| `src/domain/` | Датасет, фильтры, пресеты/дефолты графиков, инсайты |
| `src/utils/` | Числа, формат, подписи, статистика, выборка scatter, экспорт, шаринг |
| `src/components/` | Загрузка файла, фильтры, сайдбар графиков, сетка графиков, `DashboardStats`, карточки, иконки |

## Идеи для развития (не обязательны для курсовой)

- Юнит-тесты на фильтры, сводку столбцов и построение графиков; e2e на загрузку CSV.
- Загрузка очень больших файлов через Worker или бэкенд; прогресс и отмена парсинга.
- Экспорт таблицы/сводки в CSV или Excel.
- Явный выбор колонок для «ядра» фильтров, если авто-сопоставление ошиблось.
- Локализация интерфейса (не только числа в `ru-RU`).
