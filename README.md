# Real Estate Analytics Dashboard

Интерактивный веб-дашборд для исследования выборки объектов недвижимости по загружаемому CSV: **любые столбцы файла**, конструктор графиков, тёмная и светлая тема.

**Стек:** React 19, TypeScript, Vite 6, Recharts, Papa Parse.

## Возможности

### Данные и типы столбцов

- **Все столбцы CSV** попадают в таблицу данных; для каждого столбца автоматически определяется тип: *числовой* (если ≥85% непустых значений удаётся разобрать как число) или *категориальный*. Колонки `тип_дома_*` принудительно считаются категориальными.
- После загрузки по умолчанию строятся пресеты графиков по сводке (числовые и категориальные столбцы).
- Записи, прошедшие фильтры, участвуют во всех графиках без искусственного лимита по количеству строк (кроме выборки для scatter).
- **Боковые фильтры** (если в файле есть колонки, сопоставленные с «ядром» `Цена`, `Общая площадь`, `Количество комнат`): диапазоны цены и площади, комнатность. Пересчёт с `useDeferredValue` / `startTransition`.
- **Комнатность по умолчанию:** без ограничения (все значения); клик по кнопке комнатности сужает выбор.
- Если этих колонок нет, боковые фильтры не применяются — отображаются все загруженные строки (кроме полностью пустых).
- Краткая сводка в шапке (**Обзор рынка**), **автоинсайты** по выборке (цена, площадь, выбросы, комнатность и т.д.).
- Scatter после фильтрации строится по **равномерной выборке** до **1200** точек; гистограммы и категории — по полной выборке.

### Конструктор графиков

- **Гистограмма** (числовой столбец), **точечная диаграмма** (два числовых столбца), **столбцы по категориям** (частоты значений). Список графиков можно переупорядочивать (drag-and-drop) и удалять.
- **Панель графиков:** выбор типа завязан на допустимые столбцы (числовые / категориальные), **поиск по названию столбца** с подсветкой совпадений, блок **«Популярные поля»** (цена, площадь, комнаты — если есть в данных).
- **Рекомендации:** при выборе столбца **цены** в режиме гистограммы предлагаются гистограмма и точечный график «цена × площадь» (если в данных есть площадь и два числовых столбца).
- Экспорт карточки графика в **PNG** и **PDF**; в полноэкранном режиме графика те же действия в шапке модалки.

### UX

- **Skeleton** при парсинге CSV; **drag & drop** загрузки файла на стартовом экране.
- **Поделиться:** ссылка с закодированными фильтрами и набором графиков (параметр `?share=` в URL; подходит для того же набора столбцов CSV).
- **Тема** оформления в стиле нейтральный zinc + акцент indigo.

### Кэш и localStorage

Используются **два независимых ключа** (разные по смыслу записи):

| Ключ | Назначение |
|------|------------|
| `realty-dashboard-dataset-v2` | Кэш последнего загруженного CSV: данные и сводка (`CachedDataset`). Тот же файл (имя + размер + дата) открывается без повторного парсинга. Лимит ~4.5 МБ JSON; при превышении кэш не пишется, но сессия работает в памяти. |
| `realty-dashboard-ui-v1` | Тема и сохранённые **фильтры + набор графиков** по сигнатуре столбцов (`columnOrder`). При смене файла с другими столбцами подставляется своя запись или значения по умолчанию. |

Старый кэш v1 датасета не используется.

## Формат CSV

Регистр имён колонок важен. Типичный набор (все поля необязательны, кроме того что вы используете в графиках):

| Колонка | Описание |
|--------|----------|
| `Цена` | Число; при наличии — участвует в боковом фильтре «цена» |
| `Общая площадь` | м²; фильтр «площадь» |
| `Количество комнат` | Число; фильтр по комнатности |
| `Расстояние до центра (км)` | Число; как и любой другой столбец — доступен в графиках |
| `тип_дома_<название>` | Флаги `0`/`1`; в данных добавляется агрегат `houseType` |

Пустые строки отбрасываются. Ячейки парсятся как числа, где возможно (пробелы, запятая, символы валюты).

## Запуск

Требуется **Node.js 18+**.

```bash
npm install
npm run dev
```

По умолчанию: [http://localhost:3000](http://localhost:3000) (см. `vite.config.ts`).

Сборка продакшена:

```bash
npm run build
npm run preview
```

При сборке Vite выделяет отдельные чанки для React, Recharts, Papa Parse; при первом экспорте графика подгружаются `html2canvas` и `jspdf`.

## Python-утилиты (опционально)

В каталоге `scripts/` лежат вспомогательные скрипты (pandas, только для офлайн-обработки данных):

- `requirements.txt` — `pip install -r scripts/requirements.txt`
- Нормализация имён колонок, типы столбцов, очистка категорий, группировка one-hot и т.д.

Они **не** входят в фронтенд-сборку.

## Структура проекта

Код в **`src/`**, алиас `@/` → `src`.

| Путь | Назначение |
|------|------------|
| `index.html` | Оболочка; скрипт `/src/main.tsx` |
| `src/main.tsx` | Вход |
| `src/App.tsx` | Состояние, фильтрация, вёрстка, шаринг, persist UI |
| `src/types.ts` | `DataRow`, сводка по столбцам, описания пользовательских графиков |
| `src/cache.ts` | Кэш датасета v2 (`localStorage`) |
| `src/persistence/` | Ключи и настройки UI v1 |
| `src/theme.ts` | Тема и цвета Recharts |
| `src/domain/` | Датасет, фильтры, пресеты графиков, инсайты, рекомендации |
| `src/utils/` | Числа, формат, статистика, выборка scatter, экспорт, шаринг |
| `src/components/` | Загрузка файла, фильтры, сайдбар графиков, сетка графиков, `DashboardStats`, карточки, иконки |
