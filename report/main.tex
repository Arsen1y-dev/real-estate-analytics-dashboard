\intro

На агрегаторах вроде Яндекс.Недвижимость каждый день публикуются тысячи объявлений о продаже квартир: цена, площадь, этаж, тип дома, адрес. По таким данным изучают рынок недвижимости и ищут закономерности в ценообразовании~\cite{soboleva2023,belyaev2015}. При этом сам сайт для анализа неудобен: фильтры не покрывают все нужные комбинации условий, нельзя быстро сравнить два сегмента рынка и посмотреть выборку на карте в одном месте.

Данные ещё и непросто достать. Публичного API у площадки нет, карточки подгружаются через JavaScript, работает защита от автоматического сбора. Обычно приходится отдельно писать парсер, отдельно чистить таблицу и только потом строить графики~\cite{nesterov2024,selenium}. Статические отчёты в Excel или ноутбуке решают часть задач, но не дают интерактивности: при смене фильтра всё нужно пересчитывать заново~\cite{filatov2013,ahtimirov2024}.

В этой работе собран полный цикл в одном приложении: Python-пайплайн забирает объявления с Яндекс.Недвижимость, сервер хранит готовые датасеты по городам, а в браузере открывается дашборд с фильтрами, сводными показателями, графиками и картой. Подход близок к тому, как устроены другие веб-системы для анализа данных~\cite{filimonova2024,sultanov2022}.

Объект работы~--- объявления о продаже квартир на Яндекс.Недвижимость. Предмет~--- способы автоматизированного сбора этих данных, их подготовки и показа в интерактивном веб-интерфейсе.

Цель~--- разработать такую систему для анализа рынка недвижимости: парсер на Python, серверную часть с хранением данных по городам и одностраничное веб-приложение с разными правами доступа.

Чтобы этого добиться, были поставлены задачи:
\begin{enumerate}
    \item Разобраться, как устроен сайт Яндекс.Недвижимость, и выбрать схему сбора данных через Selenium с этапами «ссылки~$\rightarrow$ карточки~$\rightarrow$ подготовка CSV».
    \item Написать парсер с настройками под разные города, отслеживанием прогресса и возможностью продолжить работу после остановки или капчи.
    \item Спроектировать приложение: React и TypeScript на клиенте, Express и SQLite на сервере, общие типы и фильтры в каталоге \texttt{shared/}.
    \item Сделать дашборд~--- фильтры, блок с медианами и числом объектов, настраиваемые графики, карту, таблицу объявлений и сравнение двух наборов фильтров.
    \item Поддержать загрузку данных с сервера (Москва, Саратов) и из своего CSV, экспорт результатов, подстановку адреса по координатам с кэшем.
    \item Разделить пользователей по ролям: просмотр, полный анализ, администрирование датасета и парсера, отдельная панель для руководителя.
    \item Проверить систему на реальных данных и убедиться, что ею можно пользоваться для разбора локального рынка.
\end{enumerate}

\conclusion

В работе разработан программный комплекс для анализа рынка недвижимости на данных платформы Яндекс.Недвижимость: Python-пайплайн сбора, серверное хранение датасетов по городам и интерактивный веб-дашборд с разграничением прав доступа.

В первом разделе рассмотрены теоретические основы сбора данных из динамических веб-источников, предобработки табличных массивов и построения аналитических панелей. Обоснован переход к автоматизации браузера (Selenium) для сайтов с JavaScript-контентом.

Во втором разделе спроектирована архитектура системы: клиент (React SPA), сервер API (Express, SQLite, JSON-датасеты), модуль парсера и общий слой правил \texttt{shared/}. Описаны модель данных, REST-интерфейс, роли пользователей и подключение API Яндекс.Карт и Геокодера.

В третьем разделе приведена программная реализация: поэтапный парсер с ETL и обработкой капчи, ingest на сервер, единая фильтрация, клиентские визуализации на Recharts и карта объектов.

В четвёртом разделе выполнена проверка на данных Москвы (12\,549 объявлений) и Саратова (75 объявлений). Подтверждена работоспособность сценариев для ролей observer, analyst, admin и manager; показан пример прикладного среза рынка через фильтры дашборда. Система развёрнута на VPS (nginx, systemd) и проверена через публичный HTTPS-туннель.

Практический результат --- работающее приложение полного цикла «сбор $\rightarrow$ хранение $\rightarrow$ интерактивный анализ», пригодное для учебных и исследовательских задач по локальным рынкам жилой недвижимости.
